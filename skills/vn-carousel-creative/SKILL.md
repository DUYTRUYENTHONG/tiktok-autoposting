# Carousel sản phẩm tiếng Việt

Inspect each product reference before generating. Preserve exact product identity, bottle geometry, label, volume, colors and intended use. Existing complete carousel images may be reused after visual QA; existing captions/prompts are drafts rather than substantiation of efficacy.

Build each carousel around one customer question: hook → specific context → grounded explanation or clearly labeled illustration → offer → CTA. Use the aspect ratios accepted by the current photo-upload UI; the Sakura source carousels are 3:4. Keep large Vietnamese text, accurate accents, generous margins and a clear slide sequence. Do not force 9:16 onto a 3:4 asset set.

Use the available built-in image-generation tool for raster generation or edits; inspect local references with the image viewer first. In DeerFlow use its actual configured image-generation skill only after provider readiness is verified. Prompt preparation does not mean generation succeeded. Submit one prompt per output, retain returned artifact paths and inspect every final slide.

For Sakura the user authorized “Mua 3 tặng 1”, offline TP.HCM and online Vietnam. Do not add prices, free delivery, deadlines, equal-value gift assumptions, certifications, antibacterial claims or fake testimonials. Do not depict unverified cleaning transformations as evidence. Read and verify label instructions before instructional claims. Keep a local manifest linking angle_id, variant_id, slide order, file hash and caption; never put private product files in Git.
